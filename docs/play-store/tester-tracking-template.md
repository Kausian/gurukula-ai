## Core checklist (the "Completed core checklist?" column)

A tester "completed" it if they did: sign in → profile → note → summary →
flashcards → quiz → export → Privacy Lock → (optionally clear data) →
delete account. See `tester-instructions.md`.

## Closed-testing count reminder

If Play Console requires the **12 testers / 14 continuous days** path for your
account:

- Keep **at least 12 testers with "Opted in? = Y"** for the **full 14-day**
  window (don't let the opted-in count drop below 12).
- Recruit a **buffer** (aim ~14–16) so a couple of drop-outs don't break the
  count.
- Track the **opt-in start date** per tester; the 14 days runs while ≥12 remain
  opted in. **[Verify the exact rule shown in your Play Console.]**
